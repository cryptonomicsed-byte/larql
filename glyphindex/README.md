# GlyphIndex polyglot conformance kit

One contract, many languages. This directory holds the shared frozen vectors,
the golden graph fixture, and dependency-light ports of the **portable,
keyless surface** of the GlyphIndex sovereign-memory contract
(spec: `OSOVM/GLYPHINDEX_SPEC.md`; canonical reference implementation:
`Vantage/backend/glyph_index.py`).

Every port implements and proves the same things against the same bytes:

| Check | Source of truth |
|---|---|
| GIX-FOLD-v1 fold + Odù linkage | `vectors.json` → `fold` (5 frozen chunks) |
| Graph verbs: DESCRIBE / SELECT / WALK / INFER / merge | `glyph-graph-snapshot.json` + `vectors.json` → `walk` |
| Wire format round-trip (structural equality) | `glyph-graph-snapshot.json` |
| GIX1 envelope structural audit (keyless) | spec §3 |
| Merkle anchoring (empty root + deterministic root) | `vectors.json` → `merkle` |

The KDF vectors (`vectors.json` → `kdf`) freeze the GIX-KDF-v1 hierarchy for
legs that implement sealing (mnemopi TypeScript, Vantage Python, BIPON39
Rust); the keyless ports here don't need them.

## Ports and how to run each conformance suite

| Language | Path | Run |
|---|---|---|
| Python | `python/glyphindex.py` | `python3 glyphindex.py` |
| Go | `go/` | `go test ./...` |
| Elixir | `elixir/glyphindex.exs` | `elixir glyphindex.exs` |
| Julia | `julia/glyphindex.jl` | `julia glyphindex.jl` |
| Clojure | `clojure/glyphindex.clj` | `java -cp "<clojure+data.json jars>" -Dglyphindex.dir=. clojure.main glyphindex.clj` |
| Move | `move/` | `sui move test` (on-chain subset: fold, Odù, GIX1 audit, Merkle root) |

Sibling legs of the same contract living elsewhere:

- **Rust** — `crates/larql-glyph` (graph verbs, wire fixture, merge, anchor).
- **TypeScript** — oh-my-pi `packages/mnemopi` (`core/glyph-index`,
  `core/gix1`, MCP tools incl. `mnemopi_glyph_anchor`).
- **Zero** — zerolang `examples/glyphindex.0` (fold, envelope audit, WALK).

## Rules every port must follow

- **Canonical id is the address.** The glyph is a display alias; collisions
  are cosmetic. Ids are 64 lowercase hex chars.
- **Ordering is UTF-8 byte order** (Rust `BTreeSet<String>` semantics) for
  tags, edge sort keys, and Merkle leaf ordering.
- **WALK** is an undirected BFS over the sorted edge set, start excluded,
  results in discovery order.
- **Merge** unions tags, keeps the earliest `ts`, never drops an existing
  locator, and is idempotent.
- **Wire `ts` values** in fixtures are non-integer floats so every JSON
  emitter serializes them identically.
- New fixtures are generated by the canonical reference (or the TypeScript
  leg) and committed byte-identical wherever they are asserted.

## Adding a language

1. Implement the surface above in one self-contained file/package.
2. Load `../vectors.json` and `../glyph-graph-snapshot.json`; assert all
   five checks.
3. Wire the run command into this table. A port that passes the kit is
   wire-compatible with every other leg by construction.
